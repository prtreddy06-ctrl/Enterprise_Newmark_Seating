📱 Open Web App & Add to Home Screen
🍏 Installing on iOS Safari:
Tap the Share icon in Safari and select "Add to Home Screen". This installs a real, full-screen standalone app icon — Apple does not allow installing .ipa files outside the App Store or TestFlight, so this is the correct install method for a web-based companion app.
